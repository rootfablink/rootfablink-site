# Phase 0 and Phase 1 Scope

## Built now

- Monorepo foundation
- Next.js web app
- Locale-aware routing for English and Turkish first
- Enterprise homepage
- Authentication page shells
- Supplier dashboard shell
- Admin command center shell
- Shared role and permission contracts
- Prisma database schema for core entities
- NestJS-ready API foundation

## Next implementation priorities

1. Connect authentication to the API with password hashing, JWT access tokens, refresh tokens, and email verification.
2. Add company onboarding with validation and database persistence.
3. Add product and category management with moderation statuses.
4. Add RFQ creation, supplier matching preparation, and quotation submission.
5. Add protected admin routes for verification and product approval.
